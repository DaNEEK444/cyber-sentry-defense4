# Cyber Sentry Defense Security Stack

This repository contains the full security stack for Cyber Sentry Defense, including Pi-hole DNS filtering, Suricata IDS/IPS rules, firewall policies, deployment scripts, documentation, and network architecture. This project is designed to provide home users and small businesses with a powerful, modular cybersecurity system built on open-source tools.

---

## 📁 Repository Structure

### /pi-hole
DNS filtering configuration:
- Blocklists
- Allowlists
- Regex rules
- Unbound DNS config
- DHCP plan
- Pi-hole install script

### /suricata
Intrusion Detection System configuration:
- suricata.yaml template
- Custom rules
- Logging schema notes

### /firewall
Firewall policies:
- UFW rules
- iptables rules

### /scripts
Deployment and automation scripts:
- Pi-hole install
- Suricata install
- System hardening

### /docs
Documentation and architecture:
- Network design
- Deployment guide
- Troubleshooting
- System overview

### /branding
Cyber Sentry Defense business materials:
- Service overview
- Client onboarding
- Package descriptions

---

## 🚀 Purpose

Cyber Sentry Defense is a modular, open-source cybersecurity suite designed to:
- Block malicious domains
- Detect suspicious network activity
- Harden home and small-business networks
- Provide clear documentation and deployment paths
- Support future automation and client-facing services
