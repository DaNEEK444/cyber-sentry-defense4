# Cyber Sentry Defense Client Onboarding

Welcome to Cyber Sentry Defense. This onboarding guide explains how new clients begin working with us and what to expect during setup.

## 1. Initial Consultation
We begin with a short discovery call to understand:
- Your home or business network
- Devices and operating systems
- Security concerns
- Desired protection level

## 2. Environment Assessment
We review:
- Router model and capabilities
- Current DNS configuration
- Network layout
- Existing security tools

## 3. Deployment Plan
We provide a customized plan including:
- Recommended CSD device placement
- DNS configuration steps
- Firewall adjustments
- Monitoring setup

## 4. Installation
We assist with:
- Device setup
- Pi-hole configuration
- Suricata activation
- Firewall enforcement

## 5. Verification
We confirm:
- DNS filtering is active
- IDS alerts are logging
- Firewall rules are applied
- Network performance is stable

## 6. Ongoing Support
Clients receive:
- Monthly security reports
- Threat summaries
- Device health checks
- Optional remote support

Cyber Sentry Defense ensures a smooth, guided onboarding experience for every client.
